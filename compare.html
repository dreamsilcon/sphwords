第23章 chest /tʃest/ n.胸部，胸膛;箱子，盒子

词源 · 辨析查看原词条 →

词源：为什么 chest 既是“箱子”，又是“胸部”？

本义先是箱子。chest 来自古英语 cest / cist，再往上是拉丁语 cista、希腊语 kistē，都是“盒子、箱子、篮子”一类容器。treasure chest（宝箱）、chest of drawers（五斗柜）走的就是这条原义。

胸部义是后来的比喻引申：肋骨围成一圈，像个“盒子”护着心脏和肺，所以用 chest 指胸腔 / 胸膛。大约十五、十六世纪起这个用法固定下来，并逐渐取代部分 breast 表示“胸廓”的说法。

一句话：先是装东西的箱子，再比喻成装心肺的“胸腔盒子”——不是两个无关的词，而是同一个容器义的延伸。

辨析 chest、box 与 cage：

对比点 chest /tʃest/ box /bɒks/ cage /keɪdʒ/
释义 箱子，柜子；也指胸部 盒子，箱子（最通用） 笼子
核心感觉 较大、结实、常带盖，多用于收纳贵重或大宗物品；另有身体义 各种大小的方形容器，日常打包、装东西都常用 有栏杆 / 网眼，用来关住活物，强调“关着、出不去”
常见对象 宝箱、五斗柜、工具箱；胸部、胸腔 纸箱、鞋盒、礼品盒、邮箱 鸟笼、兽笼；也可比喻“牢笼”
搭配 treasure chest；chest of drawers；tool chest；chest pain a cardboard box；gift box；box of chocolates；inbox birdcage；cage an animal；rib cage（胸廓，肋骨像笼子）
一句话 大箱子 / 胸膛 通用的盒子 关活物的笼子

补充：rib cage 用 cage，是因为肋骨像笼子围住心肺；说身体部位本身用 chest，一般不说 box。

辨析 vapour 与 steam（steam 在第20章）：

对比点 vapour /ˈveɪ.pər/ steam /stiːm/
释义 蒸汽；气态；也可泛指烟雾、雾气 水蒸气；蒸汽（尤指热水沸腾产生的）
语气 更偏科学 / 书面；美式常写作 vapor 更日常；也可作动词（冒蒸汽；用蒸汽加热）

中文都常译成“蒸汽”，但 water vapour 偏科学说法（大气里的水汽）；茶壶、蒸汽机、看得见的白雾更常用 steam。

第16章 severe /sɪˈvɪər/ adj.严重的;严厉的;剧烈的

第22章 recreation /ˌrek.riˈeɪ.ʃən/ n.娱乐;消遣

词源查看原词条 →

词源：为什么 recreation 不是“重制 / 再创造”？

按字面拆：re-（再一次）+ creation（创造），很容易理解成“重新做出来”。但 recreation 走的是另一条词义路线。

它来自拉丁语 recreare：re- + creare，在拉丁语里本义是 refresh, restore, revive, invigorate —— 使人恢复、振作、重新有活力；名词 recreatio 还指病后复原。经古法语 recreacion 进入英语后，14 世纪先表示“恢复体力 / 精神上的恢复”，约 1400 年起又引申为“用娱乐活动让自己恢复”。

所以这里的“再创造”，不是把一件东西重做一遍，而是把人“重新造回精力充沛的状态”。工作把人耗空，运动、消遣再把人“养回来”——这才是娱乐、消遣义的来源。

和 re-creation 的区别：若真要说“重新创造”，英语常写成 re-creation / re-create（再创造；重做）。recreation（无连字符，重音在 -ˈeɪ-）固定表示娱乐、消遣。

一句话：recreation = re-create yourself（恢复自己），不是 re-create a thing（重制某物）。

第23章 lenient /ˈliː.ni.ənt/ adj.仁慈的，宽大的，宽容的

词源查看原词条 →

词源：为什么 sentence 既是“句子”，又是“宣判 / 判刑”？

两个意思看起来差很远，其实同源。sentence 来自拉丁语 sententia（看法、意见、判断），词根 sentire = 感觉、认为。本义是“心里形成的意见 / 看法”。

这条路分出两支：① 看法用完整语言说出来 → 一句完整的话 → 语法上的“句子”；② 有权威的人（尤其法官）正式说出自己的判断 → “判决、宣判”，后来也指具体刑罚。动词 sentence sb to … = 判处某人……，也是从这支来的。

一句话：都是“把看法说出来”——普通人说成句子，法官说成判决。

第24章 persevere /ˌpɜː.sɪˈvɪər/v. 坚持 锲而不舍，坚持不懈 一定要注意读音。

词根词缀查看原词条 →

词根词缀：per-（彻底；一直）+ severe（来自拉丁语 severus：严厉、严格；severe 本身也有“严重的”）→ 始终严厉认真地坚持下去 → 坚持不懈。名词 perseverance /ˌpɜː.sɪˈvɪə.rəns/ = 毅力；坚持。severe 释义见第16章。

第24章 adhere /ədˈhɪər/v.依附，黏着;遵守;坚持

词源查看原词条 →

词源：为什么 adhere 既是“黏着”，又是“遵守 / 坚持”？

来自拉丁语 adhaerēre：ad-（朝向；贴上）+ haerēre（粘住、附着）。本义就是物理上的“黏住、贴牢”（胶水、细胞表面）。同根还有 adhesive 黏合剂、hesitate（本义“卡住进退两难”）。

引申很直观：人 / 行为也像被“粘”在某物上不离开 —— 粘在规则、计划、信念上，就是 adhere to the rules / a plan / a belief = 遵守、坚持、信守。英语里常说 stick to the rules，和这里是同一幅画面。

一句话：先是东西黏住表面，再比喻人牢牢贴住规则或主张不脱落。

第24章 deserve /dɪˈzɜːv/ v.应受，应得

词源查看原词条 →

词源：为什么 deserve 是“应得”，不是“服务”？

确实含有 serve。来自拉丁语 deservire：de-（彻底、充分）+ servire（服务）→ 本义是“竭力服侍、好好效劳”。

引申路径：好好服务 → 因付出而有资格得到回报 → 应得、值得。You deserve a rest. ≈ 你这番付出，该歇歇了。

一句话：先是“充分地服务”，再变成“配得上相应的结果”（可好可坏：deserve praise / deserve punishment）。别和 Promised Land（应许之地 = 被许诺的土地）里的“应”混淆：那里是应允/许诺，不是应得。

第24章 reluctant /rɪˈlʌk.tənt/adj.不情愿的;勉强的

词根词缀查看原词条 →

词根词缀：re-（向后；对抗）+ luct-（来自拉丁语 luctari：搏斗、摔跤）+ -ant（形容词）→ 本义“往后挣、反抗”→ 心里在抗拒，所以不情愿、勉强。

记忆：心里像在跟这件事摔跤较劲，不想痛快答应 → reluctant to do sth。名词 reluctance /rɪˈlʌk.təns/ = 不情愿；勉强。

第25章 imperative /ɪmˈper.ə.tɪv/ adj.必要的;紧急的 n.必要的事;:紧迫的事

词根词缀查看原词条 →

词根词缀：im-（朝向；加以）+ per- / par-（来自拉丁语 parare：准备、安排、下令）+ -ative（形容词）→ Latin imperare = 命令、发号施令 → imperative = 带命令性质的。

同根联想：emperor / empire / imperial（皇帝 / 帝国 / 帝国的）都含同一条 “命令权、统治权” 的线（Latin imperium = 指挥权）。语法上的 imperative mood = 祈使句 / 命令式（Stand up!），也是“命令”义。

记忆：先是“命令你去做”，再引申成“必须做、刻不容缓”——It’s imperative that … ≈ 这件事像军令一样，不做不行。名词 an imperative = 当务之急。

第25章 obsession /əbˈseʃ.ən/ n.痴迷;困扰;令人着迷的人(或事物)

词根词缀 · 词源查看原词条 →

词源：为什么 session 是“会话”，obsession 却是“痴迷 / 困扰”？

两者都含 sess-，同源自拉丁语 sedere = 坐。session 来自 sessio：大家坐在一起开会 / 开庭 → 一次正式的“坐着办事”→ 会话、会议、一场课、一局游戏。

obsession 多了前缀 ob-（朝向；对着；压在……上）。拉丁语 obsidere = ob- + sedere → 本义是“对坐、围坐、围困、占据”（军队围城也用这个词根一脉：siege 围攻）。动词 obsess 早期指邪灵“占据”人身，后来指某个念头“坐在心里不走”、把脑子围住 → 挥之不去 → 痴迷、沉迷、困扰。

词根词缀：ob-（对着 / 压上）+ sess（坐）+ -ion（名词）→ 有东西对着你“坐”在心里、围住你 → obsession。动词 obsess；形容词 obsessive /əbˈses.ɪv/ = 痴迷的；强迫性的。

一句话：session = 坐在一起开会；obsession = 有东西坐在心里不走、把你围住。

第27章 audition /ɔːˈdɪʃ.ən/ n./v. 试镜，试演，试唱

词根词缀 · 词源查看原词条 →

词源：为什么 audition 是“试镜 / 试唱”？

词根是拉丁语 audire = 听。同根一大家：audio 音频；auditory 听觉的（第13章）；audience 听众 / 观众；auditorium 观众席 / 礼堂（第19章）；audit 审计（第18章）；auditor 审计员（听审账目的人）。

词根词缀：audit- / audi-（听）+ -ion（行为 / 结果）→ 本义就是“一次聆听、听审”。演员、歌手来表演一段，主考方坐着听 / 看，凭这次“听审”决定要不要人 → 试唱、试演、试镜。动词 audition for a role = 去试某个角色。

和你记得的词怎么串：audience = 来听的一群人（观众 / 听众）；audit 本义也是“听审”，后来专指正式查账（账目拿出来给人审听）；auditor 现代多指审计员，偶尔也指旁听生——不是日常说的“观众”，观众用 audience。一句话：都是“听”——听演出叫 audition，听账目叫 audit，来听的人叫 audience。
